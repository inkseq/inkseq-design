## 明确边界

- mock 服务醒目标为模拟；不会用模拟素材、演示状态或历史模型验收冒充新一轮真实生成。
- 显示的 H3 原生控制表示接口支持，历史跑通过某配置不代表当前 GPU 池已经验收。
- 成片不自动被采用；音轨编排仍沿用原剪辑计划，不伪称完成最终混音导出。
- 章节剧本/人物设定不是自动无损转译成提示词；完整提示词在镜头面板明示，用户可编辑。
- 云上传大小以 capabilities 为准；浏览器完整 ZIP 备份仍有原先单文件 30 MB、合计 120 MB 限制。大素材不静默从备份中省略。
- 登录密码由操作员在服务端配置，不提供公开注册，也不在前端放 provider API key。
- 本次只修改当前前端；没有创建 GPU、付费生成、清理本机素材或迁移原项目。

## 检验顺序

1. 在独立测试 origin 登录测试账户，建立空白云项目。
2. 创建一章一场一镜，编辑 prompt、切换引导/画布，保存云版本并重开。
3. 上传私有素材，设置首/尾帧或全能参考，确认选段，预检。
4. disabled 服务必须显示阻塞且没有 submit；mock 服务必须显示模拟标签。
5. mock 排队并回填候选；改稿后再回填，检查旧版标记与未自动采用。
6. 丢响应、409、账户切换、批次部分失败、取消、重开恢复。
7. 返回本机，核对原数据与原素材仍在。

真实 GPU / 多节点负载 / 外部费用均属后续单独验收，不由这些前端测试推出。


## 快速创作与隔离浏览器走查
